# MenuOrders - vista pública

Esta es la presentación pública de MenuOrders, una plataforma local para servicio de mesas, comandas de cocina y administración de restaurantes.

La vitrina incluye capturas reales e identidad visual. El código operativo, las credenciales, los datos y los paquetes de instalación se conservan en un repositorio privado independiente.
